# 🌱 SHURU YAHAN SE - Roman Urdu Mein

## Aapke Paas Kya Hai? 🎁

Aapke paas ab ek **POORA SYSTEM** hai jo:

### 1. 📸 Paudhon Ki Tasveer Se Bimari Pehchanta Hai
- Tamatar ki bimariyan
- Aalu ki bimariyan  
- Shimla Mirch, Makai, Angoor, Seb, etc.

### 2. 💬 **ROMAN URDU** Mein Baat Karta Hai!
- "Assalam o alaikum" → Urdu mein jawab
- "Tamatar ki bimari kya hai?" → Urdu mein tafseel
- "Paani kitna dena chahiye?" → Urdu mein tips

### 3. 💊 Har Bimari Ka Ilaaj Batata Hai
- Alamaat (Symptoms)
- Ilaaj (Treatment)
- Bachao (Prevention)

## 🚀 3 Steps Mein Chalayein

### Step 1: Terminal Kholein
Windows: Start → cmd
Mac/Linux: Terminal app

### Step 2: Yeh Likhen
```bash
cd /workspace
python3 run.py
```

### Step 3: Browser Mein Jayein
```
http://localhost:5000
```
