## 🚀 Setup Kaise Karein

### Step 1: Naye Dependencies Install Karein
```powershell
pip install openai gtts
```

Ya sab ek saath:
```powershell
pip install -r requirements.txt
```

---

### Step 2: OpenAI API Key Le Lein

**Website:** https://platform.openai.com/api-keys

**Steps:**
1. Sign up/Login karein
2. "Create new secret key" dabao
3. Copy karein (sk-... se shuru hogi)
4. Safe jagah rakho!

**Paise Add Karein:**
- Website: https://platform.openai.com/account/billing
- $5 add karein (bohat hai!)
- Naye account ko $5 free milte hain!

---

### Step 3: .env File Mein Add Karein

```powershell
# .env file banao
copy .env.example .env

# Edit karein
notepad .env
```

**File mein ye likho:**
```
OPENAI_API_KEY=sk-your_key_here
```

Save karke band karo!

---

### Step 4: Application Chalayen

```powershell
python run.py
```

**Console mein ye dikhna chahiye:**
```

✅ Using Hugging Face Model (38+ diseases)
🌐 http://localhost:5000
```

## 🐛 Agar Problem Ho

### Problem: "No OPENAI_API_KEY found"
**Solution:**
1. Check karein `.env` file hai
2. Line: `OPENAI_API_KEY=sk-...`
3. Spaces nahi honi chahiye
4. Application restart karein

---

### Problem: "Authentication failed"
**Solution:**
1. API key sahi hai check karein
2. Expired nahi hai
3. Billing setup hai
4. Naya key le lein

1. Chrome/Edge use karein (best)
2. Mic permission allow karein
