# 🌱 START HERE - Plant Health Detective

## Welcome! 👋

You now have a **fully functional plant disease detection system with an intelligent chatbot**!

## 🚀 Quick Start (30 seconds)

### Step 1: Install Dependencies
```bash
pip3 install -r requirements.txt
```

### Step 2: Run the Application
```bash
python3 run.py
```

### Step 3: Open Your Browser
```
http://localhost:5000
```
